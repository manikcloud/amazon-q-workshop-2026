# Module 01: Introduction to Amazon Q & AI-Powered Development

## 🎯 Learning Objectives
- Understand Amazon Q's capabilities and use cases
- Set up development environment
- Complete first AI-assisted coding task

## 📚 Topics Covered
- What is Amazon Q?
- AI in software development
- Amazon Q vs other AI coding assistants
- Real-world use cases and success stories

## 🛠️ Hands-On Activities
1. **Environment Setup** - Install and configure Amazon Q CLI
2. **First Interaction** - Generate your first code snippet
3. **Exploration** - Test different Q commands and features

## 📖 Resources
- [Amazon Q Getting Started Guide](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/getting-started.html)
- [Installation Instructions](./installation-guide.md)
- [Quick Reference](./quick-reference.md)

## ⏱️ Duration
**90 minutes** (60 min theory + 30 min hands-on)

## 📋 Prerequisites
- Basic programming knowledge
- AWS account access
- Development environment (VS Code recommended)
