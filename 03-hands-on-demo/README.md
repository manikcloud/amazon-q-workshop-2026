# 03 - Hands-On Demo

## 🎯 Learning Objectives
- Live demonstration of Amazon Q capabilities
- Interactive coding session with practical examples
- Q&A and troubleshooting

## 📚 Demo Activities

### 1. **🌐 Beautiful Website Development** - HTML & CSS
**Prompt:** 
```
Create a beautiful responsive website for a Computer Science Department. Include header with navigation, hero section, courses section, faculty section, and footer. Use modern CSS with gradients and animations.
```

### 2. **🧮 Python Calculator** - Algorithm Implementation
**Prompt:**
```
Create a Python calculator class with basic operations (add, subtract, multiply, divide), scientific functions (sin, cos, sqrt), and error handling. Include a simple CLI interface.
```

### 3. **📚 Teaching Aid Generator** - For Faculty
**Prompt:**
```
Generate a comprehensive lesson plan for teaching "Object-Oriented Programming concepts" to undergraduate students. Include learning objectives, examples, exercises, and assessment rubric.
```

### 4. **🔧 Code Debugging** - Fix Common Errors
**Prompt:**
```
Debug this Python function that should find the maximum element in a list but has logical errors:

def find_max(numbers):
    max_num = 0
    for num in numbers:
        if num > max_num:
            max_num = num
    return max_num
```

## 🛠️ Live Implementation

We'll start with **Demo 1: Beautiful Website Development** and create a complete CS Department website using Amazon Q assistance.
