## 🎯 Learning Objectives
- Hands-on practice with Amazon Q
- Individual coding exercise
- Apply learned concepts

## 📚 Exercise Task
**Build a Simple Web API with Amazon Q**

### Requirements:
1. Create a Python Flask API
2. Add CRUD operations
3. Generate documentation
4. Add error handling

### Steps:
1. Use Q to generate Flask boilerplate
2. Add database operations
3. Create API endpoints
4. Generate tests and documentation

## 🛠️ Expected Output
- Working Flask API
- Proper error handling
- Auto-generated documentation
- Basic unit tests
