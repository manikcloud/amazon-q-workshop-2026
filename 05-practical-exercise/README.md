# 04 - Practical Exercise

## 🎯 Learning Objectives
- Hands-on practice with Amazon Q
- Individual coding exercise
- Apply learned concepts

## 📚 Exercise Options

### **Option 1: Student Database System**
**📁 [Complete Implementation](./student-database/)**

Build a SQLite-based student management system with:
- Add student functionality
- Retrieve student by ID
- List all students with grades
- Error handling and validation

### **Option 2: Build a Simple Web API with Amazon Q**

#### Requirements:
1. Create a Python Flask API
2. Add CRUD operations
3. Generate documentation
4. Add error handling

#### Steps:
1. Use Q to generate Flask boilerplate
2. Add database operations
3. Create API endpoints
4. Generate tests and documentation

## 🛠️ Expected Output
- Working database/API system
- Proper error handling
- Auto-generated documentation
- Basic testing functionality
